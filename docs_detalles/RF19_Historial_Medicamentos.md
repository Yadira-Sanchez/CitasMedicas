# Spec Técnico: RF19 - Historial de Medicamentos y Recordatorios

## 1. Información General
- **Código y Nombre:** RF19 (Historial de medicamentos y recordatorios).
- **Módulo:** Módulo 2 - Gestión de Medicamentos y Alertas.
- **Objetivo:** Registrar y desplegar el historial cronológico de tomas confirmadas u omitidas por el usuario, proporcionando una trazabilidad clara de la adherencia al tratamiento.

---

## 2. Historia de Usuario
**Como** usuario registrado  
**Quiero** consultar el historial de mis recordatorios  
**Para** conocer las actividades que he registrado como realizadas u omitidas a lo largo del tiempo.

---

## 3. Criterios de Aceptación
- [ ] **[RF19-01] Registro Automático:** El sistema almacena automáticamente un evento en la subcolección `historial` cada vez que se confirma u omite una dosis en RF17.
- [ ] **[RF19-02] Consulta Visual:** El usuario puede acceder a una vista de historial desde la pantalla de medicamentos o perfil.
- [ ] **[RF19-03] Detalle del Evento:** Cada tarjeta del historial muestra:
    - Nombre del medicamento.
    - Fecha y hora exacta de la acción.
    - Estado (`Tomado` / `Omitido`).
- [ ] **[RF19-04] Orden Cronológico:** Los registros se presentan ordenados desde el más reciente al más antiguo (`orderBy("timestamp", Query.Direction.DESCENDING)`).
- [ ] **[RF19-05] Estado Vacío:** Si no hay registros, se muestra una ilustración/mensaje informativo ("No hay registros en el historial").

## 4. Estructura de Datos (Firestore)
    Colección: `usuarios/{uid}/historial_medicamentos/{idRegistro}`
    ```json
    {
      "id": "autogenerated_id",
      "medicamentoId": "med_123",
      "nombreMedicamento": "Ibuprofeno 400mg",
      "fechaHora": "2026-11-10 08:30",
      "timestamp": 1794222600000,
      "estado": "Tomado" // "Tomado" o "Omitido"
    }


## 5. Especificación de UI (`PantallaHistorialMedicamentos.kt`)

| Elemento Visual | Componente Compose | Acción / Lógica |
| :--- | :--- | :--- |
| **Cabecera** | `TopAppBar` con icono volver | Navega hacia la pantalla previa (`alVolver()`). |
| **Lista Historial** | `LazyColumn` | Muestra las tarjetas de historial ordenadas por fecha. |
| **Tarjeta de Registro** | `Card` elevada | Muestra el icono de verificación (Verde si fue tomado, Gris/Naranja si fue omitido), el nombre del medicamento y la fecha. |
| **Insignia de Estado** | `Surface` con bordes redondeados | Muestra la etiqueta visual "Tomado" o "Omitido". |
